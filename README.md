## Workflow

For every problem, I follow the same process:

1. Read and understand the problem.
2. Identify the appropriate algorithm or data structure.
3. Implement a solution independently.
4. Review and optimize the solution.
5. Analyze time and space complexity.
6. Save the final solution in this repository.
7. Commit and push the changes to GitHub.
